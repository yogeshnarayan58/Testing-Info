# Phase 4 (Customize Questions / Build Survey Actions) — Investigation

Per Vaibhav: the "Customize Questions" screen and the related Build Survey
action buttons live in the **question-generator** component and are wired
through the **select-panelist**/build-survey feature tree. The screen with
the heading "Please select the options below to help customise your
selections" is:

[libs/survey-mod-lib/src/lib/features/build-survey/components/question-generator/question-generator.html](../../libs/survey-mod-lib/src/lib/features/build-survey/components/question-generator/question-generator.html)

Only the 10 requested elements are covered below — nothing else in these
files is reported per the task scope.

---

### 1. Question count field/slider (`id="text-field-81"`)

**File:** [question-generator.html](../../libs/survey-mod-lib/src/lib/features/build-survey/components/question-generator/question-generator.html#L10)

**Current HTML (10 lines):**
```html
    <div class="generator-form">
      <div class="form-section">
        <div class="question-count-row">
          <niq-slider [minValue]="minQuestionCount" [maxValue]="maxQuestionCount" [value]="questionCount"
            [tickStepSize]="1" [stepSize]="1" [showTicks]="true" [variant]="'single'"
            [ariaLabel]="'Single slider thumb'" [topLabel]="'How many questions would you like?'"
            (valueChangeEvent)="onQuestionCountChange($event)">
          </niq-slider>
        </div>
        @if (isQuestionCountOutOfRange()) {
          <div class="question-count-error" role="alert">
```

**`data-test-id` exists?** No. Note: `id="text-field-81"` is not present in
this template's source — it is an auto-generated internal id rendered inside
the `<niq-slider>` design-system component at runtime (an internal text-input
counter within that component), not something this file sets. The `<niq-slider>`
host tag itself, however, is owned by this template and can carry a static
`data-test-id`.

**Proposed change (on the host tag, since the internal `text-field-81` id is
not owned by this template):**
```html
          <niq-slider data-test-id="question-count-slider" [minValue]="minQuestionCount" [maxValue]="maxQuestionCount" [value]="questionCount"
```

### 2. The 6 question type buttons (Single Choice, Multiple Choice, Rating, Net Promoter Score, Point Scale, Multi Scale)

**File:** [libs/survey-mod-lib/src/lib/features/build-survey/components/question-type-list/question-type-list.component.html](../../libs/survey-mod-lib/src/lib/features/build-survey/components/question-type-list/question-type-list.component.html#L3)

**Current HTML (10 lines / full file):**
```html
<div class="d-flex align-items-center options">
    @for (option of questionTypeOptions(); track option.label) {
    <niq-button class="question-types list-type-icon" [iconName]="option.iconName" [useSprite]="true"
        [iconPosition]="'left'" [variant]="'secondary'"
        [state]="hoveredType === option.label ? 'active' : isSelected(option.value) ? 'active' : 'default'"
        (click)="selectQuestionType(option.value)" size="medium" colorTheme="light">
        {{ option.label }}
    </niq-button>
    }
</div>
```

The 6 labels/values are defined in
[build-survey.ts](../../libs/survey-mod-lib/src/lib/features/build-survey/models/build-survey.ts#L33-L40)
(`Single Choice`, `Multiple Choice`, `Rating`, `Net Promoter Score`,
`Point Scale`, `Multi Scale`).

**`data-test-id` exists?** No.

**Proposed change:** since the button is repeated via `@for`, use a dynamic
id derived from `option.value` (each type's enum value is unique and stable):
```html
    <niq-button class="question-types list-type-icon" [attr.data-test-id]="'question-type-' + option.value" [iconName]="option.iconName" [useSprite]="true"
```
