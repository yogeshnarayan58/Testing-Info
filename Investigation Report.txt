## Executive Summary

### The Hang Scenario

When `start-from-scratch.spec.ts` calls `selectPanelistPage.setDimensionSelections()` with Product as the first dimension:

```json
{
  "dimensionTab": "productNoDataPrompt",
  "parentItems": ["#US LOC OMNI SUPER CATEGORY MA"],
  "items": ["APPLIANCES"],
  "requiresFilterIconClick": true
}
```

The following sequence occurs:

1. ✅ Product prompt clicked (`[data-test-id='ds-noDataPrompt_Product']`)
2. ✅ 1000ms delay
3. ❓ Search icon lookup (`[data-test-id='ds-filterIcon-icon']`)
4. ⏱️ **waitFor(3000ms) blocks here — may timeout**

If the search icon is not visible within 3 seconds, or if visibility detection is ambiguous, the test hangs with no clear error.

### Key Findings

| Finding | Severity | Status |
|---------|----------|--------|
| All locator element names verified | ✅ | Confirmed match |
| Selector NOT panel-scoped | ⚠️ | Generic selector could match wrong element |
| Only 1000ms wait before searchIcon lookup | ⚠️ | Insufficient pre-check |
| Timing uses 300ms instead of 500ms after search | ⚠️ | May not allow results to populate |

## 2. select-panelist.page.ts — Complete Code

**File Path:** `e2e/page-objects/survey/select-panelist.page.ts`

```typescript
import { BasePage, WebActions } from '@gfk/gta';
import { ResourceManager } from '../../utils/resource-manager';
import { ElementResource } from '../../interfaces/iElementResource';
import { NAVIGATION_TIMEOUT, PANEL_TRANSITION_DELAY,UI_STATE_UPDATE_DELAY,SMALL_TIMEOUT, ELEMENT_WAIT_TIMEOUT, DATASET_SELECTOR_TIMEOUT } from '../../constants/timeout-constants';
import selectPanelistPageResources from '../../locators/survey/select-panelist.locator.json';

const SELECT_PANELIST_PAGE_COMPONENT_NAME = 'selectPanelistPage';

interface DimensionSelection {
  dimensionTab: string; // Resource key: 'productNoDataPrompt', 'retailerNoDataPrompt', etc
  items: string[];      // Array of item names to select
  parentItems?: string[]; // Optional: Parent category items to select first (for hierarchical data)
  requiresFilterIconClick?: boolean; // Optional: Click filter icon BEFORE parent (Product, Demographic)
  filterIconClickAfterParent?: boolean; // Optional: Click filter icon AFTER parent (Period)
  skipParentSearch?: boolean; // Optional: Click parent directly without searching first (Period)
}

export class SelectPanelistPage {
  private webActionHandler: WebActions;
  private resourceManager: ResourceManager;
  
  constructor(private basePage: BasePage) {
    this.webActionHandler = basePage.getWebActions();
    this.resourceManager = new ResourceManager({});
    this.resourceManager.registerResources(
      SELECT_PANELIST_PAGE_COMPONENT_NAME,
      selectPanelistPageResources
    );
  }

  async setDimensionSelections(selections: DimensionSelection[]): Promise<void> {
    for (const selection of selections) {
      await this.setDimensionSelection(
        selection.dimensionTab, 
        selection.items, 
        selection.parentItems,
        selection.requiresFilterIconClick,
        selection.filterIconClickAfterParent,
        selection.skipParentSearch
      );
    }
  }

  private async enterTextInSearchField(inputText: string): Promise<void> {
    try {
      const searchField = this.webActionHandler.getWebElement(
        this.resourceManager.getResource('dsSearchBarInput', SELECT_PANELIST_PAGE_COMPONENT_NAME)
      );
      await searchField.waitFor(DATASET_SELECTOR_TIMEOUT);
      // Clear any existing text
      await searchField.enterText("");
      await this.webActionHandler.delay(UI_STATE_UPDATE_DELAY);  // Small delay between clear and enter
      // Enter the new input text
      await searchField.enterText(inputText);
    } catch (error) {
      throw new Error(`Failed to enter search text '${inputText}': ${error instanceof Error ? error.message : error}`);
    }
  }

  async setDimensionSelection(
    dimensionPromptResource: string,
    itemsToSelect: string[],
    parentItems?: string[],
    requiresFilterIconClick?: boolean,
    filterIconClickAfterParent?: boolean,
    skipParentSearch?: boolean
  ): Promise<void> {
    try {
      // Click dimension prompt
      const dimensionPrompt = this.webActionHandler.getWebElement(
        this.resourceManager.getResource(dimensionPromptResource, SELECT_PANELIST_PAGE_COMPONENT_NAME)
      );
      await dimensionPrompt.waitFor(ELEMENT_WAIT_TIMEOUT);
      await dimensionPrompt.click();
      await this.webActionHandler.delay(PANEL_TRANSITION_DELAY);  //Delay for panel to open

      // Step 0: Click search/filter icon ONLY if required (e.g., Product needs it, Retailer doesn't)
      if (requiresFilterIconClick) {
        const searchIcon = this.webActionHandler.getWebElement(
          this.resourceManager.getResource('searchIcon', SELECT_PANELIST_PAGE_COMPONENT_NAME)
        );
        await searchIcon.waitFor(DATASET_SELECTOR_TIMEOUT);
        await searchIcon.click();
        await this.webActionHandler.delay(UI_STATE_UPDATE_DELAY);
      }

      // Step 1: Select parent categories first (for hierarchical data like Product, Period)
      if (parentItems && parentItems.length > 0) {
        for (const parentItem of parentItems) {
          
          // Step 1a: Search for parent ONLY if skipParentSearch is false (Product) or undefined
          if (!skipParentSearch) {
            await this.enterTextInSearchField(parentItem);
            await this.webActionHandler.delay(UI_STATE_UPDATE_DELAY);

            // Wait for viewport
            const viewport = this.webActionHandler.getWebElement(
              this.resourceManager.getResource('dsSelectionsViewPort', SELECT_PANELIST_PAGE_COMPONENT_NAME)
            );
            await viewport.waitFor(DATASET_SELECTOR_TIMEOUT);
            await this.webActionHandler.delay(UI_STATE_UPDATE_DELAY);
          } else {
            // For Period: Months is already visible, no need to search
            console.log(`Skipping parent search, clicking directly`);
          }

          // Click parent CATEGORY ITEM directly (NO CHECKBOX - just click the item)
          try {
            const parentCategory = this.webActionHandler.getWebElement(
              this.resourceManager.getDynamicResource('categoryItem', parentItem, SELECT_PANELIST_PAGE_COMPONENT_NAME)
            );
            await parentCategory.waitFor(DATASET_SELECTOR_TIMEOUT);
            await parentCategory.click();
            await this.webActionHandler.delay(PANEL_TRANSITION_DELAY);  //Wait for sub-list to appear and search field to be ready
          } catch (error) {
            throw new Error(`Failed to click parent category for '${parentItem}': ${error instanceof Error ? error.message : error}`);
          }
        }
      }

      // Step 2: Click search/filter icon AFTER parent selection (Period)
      if (filterIconClickAfterParent) {
        const searchIcon = this.webActionHandler.getWebElement(
          this.resourceManager.getResource('searchIcon', SELECT_PANELIST_PAGE_COMPONENT_NAME)
        );
        await searchIcon.waitFor(DATASET_SELECTOR_TIMEOUT);
        await searchIcon.click();
        await this.webActionHandler.delay(UI_STATE_UPDATE_DELAY);
      }

      // Step 3: Select child items
      for (const item of itemsToSelect) {
        // Search for child item
        await this.enterTextInSearchField(item);
        await this.webActionHandler.delay(UI_STATE_UPDATE_DELAY);

        // Wait for viewport to populate with child item
        const viewport = this.webActionHandler.getWebElement(
          this.resourceManager.getResource('dsSelectionsViewPort', SELECT_PANELIST_PAGE_COMPONENT_NAME)
        );
        await viewport.waitFor(DATASET_SELECTOR_TIMEOUT);
        await this.webActionHandler.delay(UI_STATE_UPDATE_DELAY);

        try {
          const checkbox = this.webActionHandler.getWebElement(
            this.resourceManager.getDynamicResource('checkboxLabel', item, SELECT_PANELIST_PAGE_COMPONENT_NAME)
          );
          await checkbox.waitFor(DATASET_SELECTOR_TIMEOUT);
          await checkbox.click();
          await this.webActionHandler.delay(UI_STATE_UPDATE_DELAY);
        } catch (error) {
          throw new Error(`Failed to click checkbox for child item '${item}': ${error instanceof Error ? error.message : error}`);
        }
      }

      // Step 4: Clear search field before clicking Done
      const searchFieldBeforeDone = this.webActionHandler.getWebElement(
        this.resourceManager.getResource('dsSearchBarInput', SELECT_PANELIST_PAGE_COMPONENT_NAME)
      );
      await searchFieldBeforeDone.waitFor(DATASET_SELECTOR_TIMEOUT);
      await searchFieldBeforeDone.enterText("");
      await this.webActionHandler.delay(UI_STATE_UPDATE_DELAY);

      // Click Done
      try {
        const doneButton = this.webActionHandler.getWebElement(
          this.resourceManager.getResource('doneIcon', SELECT_PANELIST_PAGE_COMPONENT_NAME)
        );
        await doneButton.waitFor(DATASET_SELECTOR_TIMEOUT);
        await doneButton.click();
        await this.webActionHandler.delay(PANEL_TRANSITION_DELAY);  //Delay for panel to close
      } catch (error) {
        throw new Error(`Failed to click Done button for '${dimensionPromptResource}': ${error instanceof Error ? error.message : error}`);
      }

    } catch (error) {
      console.error(`setDimensionSelection failed: ${error instanceof Error ? error.message : error}`);
      throw error;
    }
  }

  async clickSelectPanelistsTab(): Promise<void> {
    try {
      const selectPanelistsTab = this.webActionHandler.getWebElement(
        this.resourceManager.getResource('selectPanelistsTab', SELECT_PANELIST_PAGE_COMPONENT_NAME)
      );
      await selectPanelistsTab.waitFor(ELEMENT_WAIT_TIMEOUT);
      console.log('✓ Select Panelists tab found, clicking...');
      await selectPanelistsTab.click();
      await this.webActionHandler.delay(PANEL_TRANSITION_DELAY);  //Wait for tab transition
      console.log('Select Panelists tab clicked');
    } catch (error) {
      console.error(`clickSelectPanelistsTab failed: ${error instanceof Error ? error.message : error}`);
      throw error;
    }
  }

  async clickSearchForPanelists(): Promise<void> {
    try {

      );
      await searchButton.waitFor(ELEMENT_WAIT_TIMEOUT);

    } catch (error) {
      console.error(`clickSearchForPanelists failed: ${error instanceof Error ? error.message : error}`);

    }
  }

  async click250Responses(): Promise<void> {
    try {
      const button250 = this.webActionHandler.getWebElement(

      );
      await button250.waitFor(ELEMENT_WAIT_TIMEOUT);
      await button250.click();
      await this.webActionHandler.delay(UI_STATE_UPDATE_DELAY);
    } catch (error) {
      console.error(`click250Responses failed: ${error instanceof Error ? error.message : error}`);
      throw error;
    }
  }

  async clickProceedToSurveyBuilder(): Promise<void> {
    try {
      const proceedButton = this.webActionHandler.getWebElement(
        this.resourceManager.getResource('proceedToSurveyBuilderButton', SELECT_PANELIST_PAGE_COMPONENT_NAME)
      );
      await proceedButton.waitFor(ELEMENT_WAIT_TIMEOUT);

      await this.webActionHandler.delay(UI_STATE_UPDATE_DELAY);
    } catch (error) {

  }

  async clickBuildSurvey(): Promise<void> {
    try {
      const buildSurveyButton = this.webActionHandler.getWebElement(

      await buildSurveyButton.waitFor(ELEMENT_WAIT_TIMEOUT);

}
```

## 5. SearchIcon Selector Ambiguity Analysis

### Exact Selector Value

**From locator.json (Line 31):**

```json
{
  "elementName": "searchIcon",
  "selectorType": "tag",
  "selectorValue": "[data-test-id='ds-filterIcon-icon']"
}
```

**Verbatim Selector:**
```
[data-test-id='ds-filterIcon-icon']
```

### The Ambiguity Problem

#### ⚠️ **Selector Is NOT Panel-Scoped**

The selector uses **ONLY** `data-test-id` attribute matching:
- ❌ No parent/container scope (e.g., no `:has()`, no `.panel-container`)
- ❌ No dimension-specific prefix
- ❌ NOT scoped like: `[data-test-id='ds-noDataPrompt_Product'] [data-test-id='ds-filterIcon-icon']`

**Instead: Just `[data-test-id='ds-filterIcon-icon']` — matches ANY element with this attribute**

#### Ambiguity Risk

If multiple dimension panels exist in the DOM simultaneously (Product, Retailer, Geography, Demographic, Period panels all present but some hidden):

1. Playwright's selector engine finds **ALL** elements matching `[data-test-id='ds-filterIcon-icon']`
2. `waitFor()` visibility check attempts to determine which one is actually visible
3. **Possible failure modes:**
   - Multiple icons match, visibility check is ambiguous
   - Icon from **wrong dimension panel** is clicked
   - Icon is technically "visible" in computed style but not interactive
   - Icon hasn't rendered yet when check happens

#### Comparison with OmniShopper Pattern

From `disc-fe-omnishopper-ui-automation/data-selector-resources.json`:
```json
{
  "elementName": "searchIcon",
  "selectorType": "tag",
  "selectorValue": "[data-test-id='ds-filterIcon']"  // Also generic, non-scoped
}
```

**OmniShopper uses the identical pattern** — generic selector that relies on visibility state management.

#### Code-Only Inference

**Why this design might work:**
- Only ONE Product panel open at a time (others are destroyed, not hidden)
- OR @gfk/gta's `getWebElement()` has built-in scoping logic
- OR Playwright's `waitFor()` + `isVisible()` correctly filters to in-viewport elements

**Why this design might fail:**
- If panels remain in DOM (just hidden), multiple icons exist
- If search icon doesn't become visible within 3000ms, timeout blocks

## 6. Missing Waits Analysis

### The Problem: Insufficient Pre-Check

**Code sequence:**

```typescript
Line 57: await dimensionPrompt.click();
Line 58: await this.webActionHandler.delay(PANEL_TRANSITION_DELAY);  // 1000ms only
// Then (Lines 61–64):
Line 61–63: const searchIcon = this.webActionHandler.getWebElement(
              this.resourceManager.getResource('searchIcon', ...)
            );
Line 64: await searchIcon.waitFor(DATASET_SELECTOR_TIMEOUT);  // 3000ms
```

### What's Missing

- After `productNoDataPrompt.click()`, there's **only a generic 1000ms delay**
- **NO explicit wait for the Product panel itself to transition/render**
- Code **assumes** after 1000ms, the panel is ready and searchIcon can be looked up

### How This Could Hang

1. **If Product panel rendering takes >1000ms:** searchIcon lookup happens before DOM is ready
2. **If searchIcon is not visible within 3000ms:** Line 64 `waitFor()` blocks for full 3000ms, then throws timeout error
3. **If error is not user-visible:** Test appears to "hang" silently

### Better Approach (Recommended Fix)

```typescript
// Instead of just generic delay:
await dimensionPrompt.click();
await this.webActionHandler.delay(PANEL_TRANSITION_DELAY);

// Add explicit panel readiness check:
const productPanelCheck = this.webActionHandler.getWebElement(
  this.resourceManager.getResource('productNoDataPrompt', SELECT_PANELIST_PAGE_COMPONENT_NAME)
);
await productPanelCheck.waitFor();  // Ensure panel is actually rendered

// THEN look for searchIcon:
if (requiresFilterIconClick) {
  const searchIcon = this.webActionHandler.getWebElement(
    this.resourceManager.getResource('searchIcon', SELECT_PANELIST_PAGE_COMPONENT_NAME)
  );
  await searchIcon.waitFor(DATASET_SELECTOR_TIMEOUT);
  await searchIcon.click();
  // ...
}
```
