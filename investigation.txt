Findings
[P2] Tagged tests cannot run independently.
Both serial suites create basePage inside the first test. Running a focused tag such as @ValidateSurvey, @SaveDraft, or @ReviewModeActions excludes that setup test, leaving basePage undefined. Some review-mode tests also depend on the previous test leaving the page in review mode. Move environment setup into fixtures/hooks and make tagged cases establish their own required state—or consolidate them into one explicitly stateful scenario.
Start-with-prompt setup · Start-from-scratch setup · Dependent review test
[P2] The validation test accepts outcomes that contradict its following assertions.
It accepts “complete,” “recommended,” or “needed,” but then always requires a recommendation tag and Optiq feedback link. A successful “Validation complete” response with no recommendations will fail. Return an outcome enum and assert recommendation controls only for outcomes that provide recommendations.

The previously active publish case is now test.fixme, and its Jira reference is still <defect ID to be added>. That permits publishing regressions indefinitely while CI remains green. Restore the test or add a real defect reference, owner, and removal condition for the quarantine.
