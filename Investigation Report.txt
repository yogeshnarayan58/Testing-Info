Real root cause: base-page-factory.ts got testId from process.env.__CURRENT_TEST_ID__ || global.__CURRENT_TEST_ID__, which lt-session-reporter.ts's onTestBegin() sets. But Playwright reporters run in the main process while test files run in separate worker child processes — so that env/global write is never visible where createBasePage() actually runs. testId was therefore always null, so the precise per-test mapping file was never written, leaving everything dependent on a fragile 60-second timestamp-proximity fallback.

Fix: base-page-factory.ts now reads test.info().testId directly (imported test from @playwright/test), which works because it executes in the same worker process as the running test — no cross-process channel needed.
