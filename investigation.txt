# Implementation Log 5 — Survey Home Page Tiles (`niq-report-card`)

## What was found

The 4 home page tiles (Start from scratch / Start with a template / Start
with a prompt / Import survey) all live in this single file, each as a
top-level `<niq-report-card>`.

**The premise that `data-test-id` was on the outer `<niq-report-card>` while
the `(click)` handler lived on some different inner element does not hold
for this file** — investigation found the opposite: for the two tiles that
are actually wired up, `(click)` and `data-test-id` are **already on the same
element** (the `<niq-report-card>` host itself), with no separate inner
clickable element to move anything to:

```html
<niq-report-card variant="one-third" size="small" (click)="navigateToSelectPanelist()" data-test-id="start-from-scratch">
...
<niq-report-card size="small" (click)="navigateToAiflow()" data-test-id="start-with-prompt">
```

`navigateToSelectPanelist()` and `navigateToAiflow()` are defined directly on
[my-assets-page.component.ts](../../libs/survey-mod-lib/src/lib/features/my-assets/components/my-assets-page.component.ts#L32-L37)
and bound straight to the `<niq-report-card>` host's native `click` event
(which bubbles up from anything rendered inside it) — there is no nested
`<button>`/`<a>`/wrapper element in this template carrying its own separate
click binding. So **no removal/move was performed** for `start-from-scratch`
or `start-with-prompt` — doing so would have meant deleting the id from the
only element that has it, with nowhere correct to relocate it to, and no
duplication existed to begin with.

**What was actually missing:** the other two tiles — "Start with a template"
and "Import survey" — have **neither** a `(click)` handler **nor** a
`data-test-id` today; they are not yet wired for navigation (likely
unimplemented features). Per the instruction not to change any binding or
logic, no `(click)` was added. `data-test-id="start-with-template"` and
`data-test-id="import-survey"` were added to their respective
`<niq-report-card>` elements — the same (only) element used consistently by
the other two tiles — so all 4 tiles now carry the requested ids in a
consistent, non-duplicated location.
