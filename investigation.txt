## Change 1: TC_BS_10 toast race (`survey-builder.page.ts`)

- `saveDraft(title)`:
  1. Waits for any old "Survey saved as draft successfully" toast to be hidden (up to `MEDIUM_TIMEOUT`). If it is still visible after that, it throws, so a leftover toast from TC_BS_10a cannot give a false pass.
  2. Clicks Save draft.
  3. Waits up to `MEDIUM_TIMEOUT` for whichever appears first: the save dialog's title input (`saveCopyTitleInput`) or the toast text (`saveDraftSuccessToast`), using Playwright `locator.or()`. Both selectors come from the locator JSON.
  4. Dialog showed: fill and save as before (`fillSaveCopyDialog`). Toast showed first: return (already-saved path).
- `isDraftSavedToastVisible()`: now `return await toast.isVisible(MEDIUM_TIMEOUT)`, so the `catch` works. The literal `10000` is replaced by the constant (same value).
- `registerSaveDraftTest` (TC_BS_10) is unchanged, so the Scratch spec's TC_BS_10 is untouched. Its Scratch run takes the already-saved path.
- Behaviour change to know about: the old code waited only 3 s for the dialog; the new code waits up to 10 s for either signal, and throws if neither shows.
- `SAVE_DIALOG_APPEAR_TIMEOUT` is no longer used anywhere; the constant itself is still in `timeout-constants.ts` (not removed, no constants were added).
