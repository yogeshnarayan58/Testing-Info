## 4. Reuse from existing helpers

- `start-with-prompt.page.ts` already reuses `dataset-selection.helper.ts` (`searchAndSelectDatasetHelper`) for dataset search/select — same as `panelist-flow.helper.ts`'s underlying `SelectPanelistPage`.
- `SelectPanelistPage` (used directly in `start-with-prompt.spec.ts`) covers dimension selection, response-count, and Build Survey-loaded check — reusable as-is for the AI flow's panelist step.
- `surveyBuilder.page.ts` already has `getQuestionNumbers()`, `clickAddQuestion()`, add-question-type flows — reusable pattern for asserting generated question counts, but it targets the manual "Add question" editor, not the AI generator's `question-count-slider`/`generate-questions` button, which have no page-object coverage yet.

## 5. UNKNOWN / not confirmed

- `swp-codegen-recording.txt` (AI flow codegen recording, Phase 2 request) — also not found anywhere in the workspace.
- Which component renders `[data-testid='quick-survey-quick-1']` (start-with-prompt entry tile) — not in `libs/survey-mod-lib` or `src/app`; must be an external npm package not vendored into this workspace.
- Numeric readout of the question-count slider — `niq-slider` is `SliderModule` from `@nielseniq/athena-core` (third-party, not in workspace), so its rendered DOM/attributes cannot be confirmed from source.
