# Phase 5 (Review Mode / Question Cards) — Investigation

Component located: [libs/survey-mod-lib/src/lib/features/build-survey/components/review-mode/review-mode.component.html](../../libs/survey-mod-lib/src/lib/features/build-survey/components/review-mode/review-mode.component.html)
(same `build-survey/components/` folder as the Phase 4 components). The
Review Mode *action buttons* (Select All / Expand All / Collapse All /
Delete / Exit Review Mode) actually live in
[survey-header.component.html](../../libs/survey-mod-lib/src/lib/features/build-survey/components/survey-header/survey-header.component.html)
(shown conditionally via `@if(isReviewMode())`), while the per-question card
list (checkbox, drag handle) lives in `review-mode.component.html` itself.
The individual question actions (refresh-with-AI, per-question delete, and
the question text input) live in
[preview-mode.component.html](../../libs/survey-mod-lib/src/lib/features/build-survey/components/preview-mode/preview-mode.component.html)
and
[question-editor/choice-editor/choice-editor.component.html](../../libs/survey-mod-lib/src/lib/features/build-survey/components/question-editor/choice-editor/choice-editor.component.html)
respectively.

Only the 10 requested elements are covered below.

**Current HTML (10 lines):**
```html

            Delete
        </niq-button>

        <niq-button class="review-mode" [variant]="'ghost'" size="medium" (click)="reviewModeService.toggleAllChecked()">
            {{ allSelected() ? 'Unselect All' : 'Select All' }}
        </niq-button>

        <niq-button class="review-mode" [variant]="'ghost'" size="medium" (click)="reviewModeService.setAllCardsCollapsed(false)">
            Expand All
        </niq-button>
```

**`data-test-id` exists?** No.

**Proposed change:**
```html
        <niq-button class="review-mode" data-test-id="select-all-questions" [variant]="'ghost'" size="medium" (click)="reviewModeService.toggleAllChecked()">
```

### 4. Per-question checkbox (inside Review Mode)

**File:** [review-mode.component.html](../../libs/survey-mod-lib/src/lib/features/build-survey/components/review-mode/review-mode.component.html#L8)

**Current HTML (10 lines):**
```html
            @for (question of questions(); track question.questionNumber ?? $index) {
            <div class="d-flex align-items-center g-24" cdkDrag cdkDragPreviewContainer="parent"
                (cdkDragStarted)="onDragStart($event, $index)">
                <niq-checkbox size="large" [checked]="reviewModeService.isChecked($index)" [error]="false"
                    (click)="reviewModeService.toggleChecked($index)"></niq-checkbox>
                <div class="question-number">{{ question.questionNumber }}.</div>
                <niq-accordion size="large" border="none" cdkDragHandle [primaryText]="question.question"
                    class="accordions" (toggle)="reviewModeService.toggleCardCollapsed($index)" expandIcon="collapse"
                    collapseIcon="expand" [class.collapsedState]="reviewModeService.isCardCollapsed($index)"
                    [prefixIcon]="reviewModeService.isCardCollapsed($index) ? 'drag-drop-circle' : ''"
                    [isExpanded]="!reviewModeService.isCardCollapsed($index)" [useSprite]="true">
```

**`data-test-id` exists?** No.

**Proposed change:** repeated via `@for`, so use a dynamic id keyed on the
question's index/number:
```html
                <niq-checkbox [attr.data-test-id]="'select-question-' + $index" size="large" [checked]="reviewModeService.isChecked($index)" [error]="false"
```

### 7. Drag handle used to reorder a question (currently `.cdk-drag`)

**File:** [review-mode.component.html](../../libs/survey-mod-lib/src/lib/features/build-survey/components/review-mode/review-mode.component.html#L6)

The `cdkDrag` directive (source of the auto-added `.cdk-drag` class) sits on
the whole question row `<div>`; the actual visual "drag handle" icon is
inside the accordion via a `.drag-handle` wrapper further down, but the CDK
`cdkDragHandle` directive itself is placed on the `<niq-accordion>` tag, not
on that visual wrapper.

**Current HTML (10 lines):**
```html
        <div class="card-wrapper" cdkDropList [cdkDropListData]="questions()" [cdkDropListAutoScrollDisabled]="false"
            (cdkDropListDropped)="drop($event)">
            @for (question of questions(); track question.questionNumber ?? $index) {
            <div class="d-flex align-items-center g-24" cdkDrag cdkDragPreviewContainer="parent"
                (cdkDragStarted)="onDragStart($event, $index)">
                <niq-checkbox size="large" [checked]="reviewModeService.isChecked($index)" [error]="false"
                    (click)="reviewModeService.toggleChecked($index)"></niq-checkbox>
                <div class="question-number">{{ question.questionNumber }}.</div>
                <niq-accordion size="large" border="none" cdkDragHandle [primaryText]="question.question"
                    class="accordions" (toggle)="reviewModeService.toggleCardCollapsed($index)" expandIcon="collapse"
                    collapseIcon="expand" [class.collapsedState]="reviewModeService.isCardCollapsed($index)"
```

**`data-test-id` exists?** No.

**Proposed change:** since this row repeats via `@for`, use a dynamic id on
the `cdkDrag` row (the element matched by `.cdk-drag` today):
```html
            <div class="d-flex align-items-center g-24" [attr.data-test-id]="'reorder-question-' + $index" cdkDrag cdkDragPreviewContainer="parent"
```
