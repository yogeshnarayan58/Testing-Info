# Phase 2 (Response Count Controls) — Investigation

File searched: [libs/survey-mod-lib/src/lib/features/select-panelist/components/select-panelist.component.html](../../libs/survey-mod-lib/src/lib/features/select-panelist/components/select-panelist.component.html)

## 1. Location

Both the response-count buttons (100/150/200/250/300/400/500, plus the
dynamically-appended 600/700/800/900/1000 when "More options" is expanded) and
the "+ More options" toggle button are defined **directly in this same file**
— they are not in a child/sibling component template. They live inside the
`<panelist-dataselector>` element's projected content, in the
`div.responses-frame > div.responses` block.

The count values themselves (`100, 150, 200, 250, 300, 400, 500` plus the extra
`600, 700, 800, 900, 1000`) come from `responseCounts` / `additionalResponseCounts`
in [select-panelist.component.ts](../../libs/survey-mod-lib/src/lib/features/select-panelist/components/select-panelist.component.ts#L62-L63),
exposed to the template via the `filteredResponseCounts` getter (line 226).

## 3. `data-test-id` status and proposals

Neither button currently has a `data-test-id`.

Existing style reference in this file: `data-test-id="proceed-to-survey"` —
kebab-case, verb/noun phrase, no `btn-`/`-button` prefix or suffix.

### Response count button — proposed change

Since these buttons are generated dynamically per `count` value, the id must be
interpolated per-instance (each count needs a distinct, stable id for
automation to target a specific response count):

```html
            <button [class.selected]="selectedResponses === count" (click)="selectResponse(count)" [attr.data-test-id]="'select-response-count-' + count">{{ count }}
```

Resulting ids: `select-response-count-100`, `select-response-count-150`,
`select-response-count-200`, ... `select-response-count-1000`.

### "+ More options" button — proposed change

```html
            <button class="more-options" type="button" data-test-id="toggle-more-response-options" (click)="toggleMoreResponseOptions()">
```

No changes have been applied — this file is investigation/proposal only.
