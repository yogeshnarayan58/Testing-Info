## Phase 1 - Investigation (test-ids)

Scope: every locator in `e2e/locators/survey/*.json`, cross-checked against `libs/**/*.html` (app source) and against actual usage in `e2e/page-objects` / `e2e/tests`.

Notes:
- "Shared library" means the target element is rendered internally by a `niq-*` / `crf-uic-*` / `crf-data-selector-panel-v2` / `re-dataset-picker` component and is not an element we author in our own `libs/**/*.html` templates, so no test-id can be added to it from this repo.
- A few elements use `data-testid` (no hyphen) instead of the repo's `data-test-id` convention — these are called out explicitly in the "TEST-ID EXISTS, NOT USED" table since they are a naming inconsistency, not a missing attribute.
- Dynamic/toast messages created via `ToastService.InsertToast(...)` (TS code, not HTML) are treated as "shared library" since there is no template element to annotate.
