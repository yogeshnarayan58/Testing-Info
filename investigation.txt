All points are motioned below are tested on Dev and working as expected.

1. AI-generated survey title in Optiq flow
Fix: In AI flow, the survey title is now taken from the title returned by the generate-questions API. Scratch flow is unchanged.
How to verify: Open survey/aiflow/build-survey, generate questions, and verify that the header displays the title from the API response instead of "Untitled Survey."

2. "Last refreshed" date persists after reload
Fix: When a saved draft reloads, the app retrieves the selected dataset's refresh date and restores it in the footer.
How to verify: Select a dataset, go to Build Survey, save a draft, refresh the page, and verify that the "Last refreshed" date is still displayed.

3. Deleting all questions keeps the user in Build Survey
Fix: In AI flow, deleting all questions keeps the user on Build Survey and displays the Add Question options. It no longer returns the user to the generator screen.
How to verify: Generate questions, delete all of them, and verify that the page remains on aiflow/build-survey with the Add Question options visible.

4. Single question-count error with consistent color
Fix: The duplicate slider error has been removed, leaving a single message: "Please enter a value between 3 and 10." The error now uses the shared error color token (#680404).
How to verify: In AI flow, enter an out-of-range value such as 1444 and verify that only one error message is displayed.

5. Drag and drop in Build Survey
Fix: Question reordering works correctly, and the drag icon remains in its original position.
How to verify: Add two or more questions, drag a question using the drag handle, and verify that the order updates correctly.

6. First Rating/NPS question loses focus while typing
Fix: The first question no longer loses focus, saves unexpectedly, or closes while the user is typing. It saves only after a valid outside click or save action.
How to verify: Create a new survey, add a Rating or NPS question first, type into its fields, and verify that the editor remains active and editable.

7. Same question type can be selected again
Fix: Deleting the last question clears the previously selected question type.
How to verify: Add a Single Choice question, delete it, and then select Single Choice again. A new question editor should open.

8. Duplicate survey cannot be saved without a title
Fix: Draft saves now reject empty or whitespace-only titles for both new and duplicated surveys. An error toast is displayed with the message: "Survey request validation failed: name is required."
How to verify: Duplicate a survey from My Assets, clear the title, and click Save Draft. Verify that the error message is shown and the survey is not saved.
