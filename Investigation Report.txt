### 5. Dedupe `navigateToSurvey()` / base URL logic into one shared utility

Partially deduped. What's shared:

[e2e/page-objects/common/common-page.ts:35-38](page-objects/common/common-page.ts#L35-L38):
```ts
public buildUrl(baseURL: string, relativePath: string): string {
  const normalizedBaseURL = baseURL.endsWith('/') ? baseURL : `${baseURL}/`;
  return new URL(relativePath, normalizedBaseURL).toString();
}
```
This base-class method is used by all 3 page objects that need it: [login.page.ts:89](page-objects/common/login.page.ts#L89), [start-from-scratch.page.ts:19](page-objects/survey/start-from-scratch.page.ts#L19), [start-with-prompt.page.ts:21](page-objects/survey/start-with-prompt.page.ts#L21) — the endsWith('/') + `new URL()` normalization logic itself is no longer duplicated (a comment in `common-page.ts` explicitly documents this extraction).

What's **still** duplicated — the `navigateToSurvey()` method itself, byte-for-byte identical in both places:

### 10. General DRY scan — additional reusability opportunities found

Beyond the dataset-selection duplication (item 3) and navigateToSurvey/base-URL duplication (item 5), the following duplicated logic was found across `e2e/page-objects/` and `e2e/tests/`:

1. **Identical dataset-confirmation boilerplate duplicated in both spec files**
   - [e2e/tests/survey/start-from-scratch.spec.ts:9-14](tests/survey/start-from-scratch.spec.ts#L9-L14)
   - [e2e/tests/survey/start-with-prompt.spec.ts:9-14](tests/survey/start-with-prompt.spec.ts#L9-L14)
   ```ts
   const datasetNames = Object.keys(testData.datasets) as Array<keyof typeof testData.datasets>;
   const DATASET_NAME = datasetNames[0];
   const datasetConfig = testData.datasets[DATASET_NAME];

   if (!datasetConfig) {
     throw new Error('No dataset found in dev-test-data.json');
   }
   ```
   Byte-for-byte identical in both files. Could be a single exported helper, e.g. `getDefaultDatasetConfig()` in a shared test-data util.

2. **Identical `test.afterAll` browser-close block duplicated in both spec files**
   - [e2e/tests/survey/start-from-scratch.spec.ts:22-26](tests/survey/start-from-scratch.spec.ts#L22-L26)
   - [e2e/tests/survey/start-with-prompt.spec.ts:22-26](tests/survey/start-with-prompt.spec.ts#L22-L26)
   ```ts
   test.afterAll(async () => {
     if (basePage) {
       await basePage.getWebActions().closeBrowser();
     }
   });
   ```
   Could be a shared `registerBrowserCleanup(() => basePage)` fixture/helper.

3. **`applyEntireDataset()` / `applyDataset()`'s "choose view" dialog handling is near-identical logic**
   - [e2e/page-objects/survey/start-from-scratch.page.ts:145-166](page-objects/survey/start-from-scratch.page.ts#L145-L166) (`applyEntireDataset`)
   - [e2e/page-objects/survey/start-with-prompt.page.ts:135-158](page-objects/survey/start-with-prompt.page.ts#L135-L158) (`applyDataset`, second half)
   Both do: get `dialogElement` → `isVisible().catch(() => false)` → if not shown, return → else `waitFor` + delay + click `applyButton`. Candidate for a shared `applyDatasetIfDialogShown()` helper on `CommonPage` or a new shared dataset-flow file.

4. **`getBasePage()` duplicated verbatim in both page objects**
   - [e2e/page-objects/survey/start-from-scratch.page.ts:170-172](page-objects/survey/start-from-scratch.page.ts#L170-L172)
   - [e2e/page-objects/survey/start-with-prompt.page.ts:175-177](page-objects/survey/start-with-prompt.page.ts#L175-L177)

5. **`panelist-flow.helper.ts` already exists as a real extracted helper but is unused**
